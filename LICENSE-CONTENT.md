# Lisensi konten

Konten pelajaran di repo ini dilisensikan dengan
[Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/deed.id).

Yang termasuk konten:

- `content-src/orisinal/` (sumber unit: dialog, bacaan, kosakata, soal)
- `content-src/ilustrasi/` dan `web/public/img/o/` (ilustrasi)
- `web/public/audio/o/` (audio)
- `web/src/content/` (konten hasil build)
- `docs/kurikulum/` (kerangka kurikulum dan ringkasan unit)

Artinya, Anda boleh menyalin, membagikan, dan mengubah konten ini, termasuk untuk keperluan
komersial, dengan dua syarat:

1. **Atribusi:** sebutkan "arabic.yogency.work dan para kontributor" beserta tautan ke repo ini.
2. **Berbagi serupa:** hasil turunannya harus dilisensikan dengan CC BY-SA 4.0 juga.

Catatan:

- Ilustrasi dibuat dengan bantuan model pembuat gambar, dan audio dibuat dengan Azure TTS.
  Lisensi ini berlaku sejauh ada hak cipta atas berkas tersebut.
- Kode program (semua yang bukan konten di atas) memakai lisensi [MIT](LICENSE).
- Repo ini tidak memuat materi *Al-Arabiyah Baina Yadaik*. Hak cipta buku tersebut milik penerbitnya
  dan tidak tercakup lisensi ini.
