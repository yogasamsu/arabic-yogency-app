# Keamanan

Jika menemukan celah keamanan, **jangan buka issue publik**. Laporkan lewat
[GitHub Security Advisories](../../security/advisories/new) (tab *Security* → *Report a vulnerability*)
di repo ini. Sertakan langkah untuk mereproduksi dan dampaknya.

Kami akan membalas secepatnya. Ini proyek nirlaba yang dikelola sukarelawan, jadi tidak ada bug bounty.
